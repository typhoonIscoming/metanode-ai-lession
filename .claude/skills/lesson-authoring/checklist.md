# Lesson Acceptance Checklist

发布一课前逐条勾选。任意一条不过则不视为完工。

## A. 文件齐备

- [ ] `lessonN/README.md` 存在并非空
- [ ] `lessonN/讲稿.md` 存在（lesson 3+ 必备；lesson 1/2 可豁免）
- [ ] `lessonN/lessonN.pptx` 存在，文件 size 合理（80KB-600KB；过小说明只有几页）
- [ ] `lessonN/lessonN.pdf` 存在，由 pptx 导出（`libreoffice --headless --convert-to pdf`）
- [ ] `lessonN/demo/` 至少 1 个子目录（即使本课重点不在 demo，也要有最小可演示样例）
- [ ] `lessonN/homework/` 至少 1 个任务子目录，含 `README.md`
- [ ] 涉及 MCP / 项目代码的课：`lessonN/project/` 与 `.mcp.json`（或 `.gitignore`）落位

## B. README 内容（学员讲义）

- [ ] H1 标题为 `# 第 N 课：<topic>`
- [ ] 开场段衔接上一课（不是凭空开始）
- [ ] 时长 + 主题列表 + 「跟着课件做」引用块
- [ ] `## 〇、前置确认（30 秒）` 存在，每条用一行命令可验证
- [ ] 至少 2 个 `## X、动手做` 章节
- [ ] 每个动手做含：可粘贴命令 + 期望输出 + 排错表
- [ ] `## 关键认知` 含口诀或记忆框（在代码块里）
- [ ] `## 反模式（3 条）` —— **恰好 3 条**，编号 + 粗体小标题
- [ ] `## 作业` 链接到 `homework/<task>/README.md`，30 分钟内可完成
- [ ] `## 学完这课你能做什么` 至少 4 条可验证能力点
- [ ] `## 延伸阅读` 表格 + 链接

## C. README 风格

- [ ] 全文命令式（无"我跑了 X，结果 Y"这种过去时叙述）
- [ ] 路径明确（无"在那个目录下" / "等等" / "..." 类省略）
- [ ] prompt 整段可粘贴，不被分行打断
- [ ] PATH 改动后明确说"新开终端"
- [ ] 含网络外部依赖时给镜像或 fallback（如 `data-api.binance.vision`）
- [ ] 含 token / PAT 时提供 `*.example` 占位示例
- [ ] 时间字面量如出现，使用 UTC + `Z` 或 `+00:00`

## D. 讲稿（讲师口播）

- [ ] frontmatter blockquote 含 时长 / 配套讲义 / 配套课件
- [ ] 章节用 `## [mm:ss — mm:ss] §章名（X 分钟）` 格式
- [ ] 章节顺序与 README 主章节对齐
- [ ] 第一人称 + 口语化（"好，我们开始"、"你们"）
- [ ] 至少一段真实战例（"我去年看过…"）
- [ ] 收束段铺垫了下一课
- [ ] 时间块加和接近"约 X 分钟" 的总时长（误差 ≤ 2 分钟）

## E. 课件 PPTX

- [ ] 总页数 24-32（封面 1 + 议程 1 + 主题 4-6 页/主题 + 收束 1）
- [ ] 正文字号 ≥ 14pt，代码块 ≥ 12pt
- [ ] 中文字体为 Microsoft YaHei，等宽为 Consolas
- [ ] 调色板与上一课不同（视觉避免雷同）
- [ ] 封面含课题、副标题、Lesson 编号 / 讲师 / 日期占位
- [ ] 议程页与 README 主章节对齐
- [ ] 至少 1 张代码示例页（mono 字体）
- [ ] 收束页列出"学完这课你能做什么"

## F. 作业

- [ ] 30 分钟内可完成；如超出，砍范围或拆主任务+加分项
- [ ] 提交清单 ≤ 4 条
- [ ] 含还原命令（`git checkout` / `rm` 等）
- [ ] 涉及外部账户/PAT：明示最小权限 + 脱敏方式

## G. 一致性 & 衔接

- [ ] 开场段引上一课 ✓
- [ ] 收束（README 末段或讲稿尾段）预告下一课 ✓
- [ ] 课程能力点与 `plan_v2.md` 第 N 课段对得上
- [ ] 引用其他课的文件路径都存在（无死链）

## H. 最终冒烟（cold-run）

让一个**完全没看过这一课**的人（同事、另一会话的 Claude）按 README 跑一遍：
- [ ] 不需要回头问"这一步是什么意思"
- [ ] 所有命令一次跑通（或排错表能覆盖踩坑）
- [ ] 作业能 30 分钟内完成

任何回头问 → 修 README，再冒烟。
