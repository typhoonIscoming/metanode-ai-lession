# Lesson 6 (Harness 设计 — Superpowers 风格) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 写完 lesson 6 全部教学产物（README / 讲稿 / pptx / pdf / demo / homework），并在 `lesson6/project/` 里用 Superpowers 的 `writing-plans` + `executing-plans` 跑完一个**多周期回测**长任务，**真实演示** "干一半 → /clear → 用 plan 续上"，最终产出 `reports/multi_period.md`。

**Architecture:**
- `lesson6/project/` 是 lesson5/project/ 的快照 + 新加 `plans/` 和 `reports/` 两个目录
- Plan 文件 `plans/multi-period-backtest.md` 列出 6 个 scenarios（BTCUSDT × ETHUSDT × limit 30/60/90），每个 scenario 是一个跑一次 `run_backtest(dual_ma, symbol=X, limit=L)` + 落一行结果的小任务
- "执行" 分两阶段：阶段 1 跑前 3 个 scenarios（BTC × {30,60,90}）然后**真模拟 /clear** 写 handoff；阶段 2 派一个**新 subagent** 只看 handoff + plan 文件，续完后 3 个（ETH × {30,60,90}）
- 阶段 2 完成后聚合所有 6 个 scenarios 的结果到 `reports/multi_period.md`，让学员看到"上下文断了，但任务因为有 plan 在没断"

**Tech Stack:** Python 3.11 / pandas / numpy / matplotlib（lesson 4 已装）/ Superpowers skills（lesson 2 已装：writing-plans / executing-plans）/ python-pptx / LibreOffice / pdftoppm。
