# 策略代码约定

适用于 `project/strategies/*.py` 下的所有文件。

## 函数签名

每个策略文件**必须**导出一个**主函数**，签名严格为：

```python
def <strategy_name>(df: pd.DataFrame) -> pd.Series:
    ...
```

参数：
- `df`：来自 `backtest.load_ohlc()`，索引为 UTC 时间戳，列含 `open / high / low / close / volume`。
- 返回值：`pd.Series`，索引同 `df.index`，值 ∈ {-1, 0, +1}。

## 防 lookahead

**禁止**写出"用今日 close 决定今日信号"的代码：

```python
# ❌ 错：今天的信号读今天的 close
return (df["close"] > df["close"].rolling(7).mean()).astype(int)

# ✅ 对：今天的信号只基于昨天及以前
ma = df["close"].rolling(7).mean()
return (df["close"].shift(1) > ma.shift(1)).astype(int)
```

> `backtest.run_backtest` 内部也会做一次 `signal.shift(1)`，但你的策略层面**仍然要按"信号决定时不能看未来"写**。两层防御。

# Spec: dual_ma 策略

## 接口

### `dual_ma.dual_ma(df, short_window=7, long_window=14)`

**输入**：
- `df: pd.DataFrame`：来自 `backtest.load_ohlc()`，索引 UTC 时间戳，列含 `close`（其他列可能存在但不强制使用）
- `short_window: int`：短均线窗口（默认 7）
- `long_window: int`：长均线窗口（默认 14）

**输出**：
- `pd.Series`：索引同 `df.index`，值 ∈ {0, +1}（本策略不做空）

## 行为细则

### 信号规则

设 `ma_s = df["close"].shift(1).rolling(short_window).mean()`、`ma_l = df["close"].shift(1).rolling(long_window).mean()`。

| 状态 | 当日信号 |
|---|---|
| `ma_s > ma_l` 且 昨日 `ma_s ≤ ma_l`（金叉） | `+1` |
| `ma_s < ma_l` 且 昨日 `ma_s ≥ ma_l`（死叉） | `0` |
| 其他（持仓维持） | 与昨日信号相同 |

### 边界

- `df` 行数 < `long_window` 时返回全 `0`
- 起始期（任一 MA 为 NaN）信号为 `0`

### lookahead 防护

`ma_s` 和 `ma_l` 用 `df["close"].shift(1).rolling(...)` 计算，确保信号决定时不读今日 close。

## 不支持

- 做空（短均线下穿不返回 -1，仅返回 0）
- 仓位分级（始终全仓 / 空仓二态）
- 自定义价格列（仅用 close）

## 兼容性

可被 `backtest.run_backtest(dual_ma)` 直接调用（仅依赖 `df["close"]`）。
```

```markdown
# Design: dual_ma 策略

## 备选方案对比

| 方案 | 实现复杂度 | 教学清晰度 | 选择 |
|---|---|---|---|
| A. close vs MA（简单突破） | 低 | 高，但和 lesson 4 ma_crossover_7 雷同 | ❌ |
| B. 短 MA vs 长 MA（金叉死叉，本提案） | 中 | 高，经典量化教科书例 | ✅ |
| C. MACD（DIF/DEA） | 高 | 高，但额外引入 EMA 概念，超出 25 min | ❌ |

## 关键技术决策

### 1. 用 `shift(1)` 防 lookahead

每条均线在计算后再 `.shift(1)`，让"今日的 ma_s" 实际是"截至昨日的 7 日均值"。这是策略层防护；`backtest.run_backtest` 内部还会再 shift 一次（信号→下日收益），共两层。

### 2. 不做空

教学定位是"看清趋势跟踪与持仓管理"，加做空会让回撤指标和胜率解读变复杂。`return 0` 即空仓。

### 3. 状态保持

金叉之后到死叉之前**所有日子**都返回 `+1`，而不是只在金叉那一天给信号。这样 `signal.shift(1) * daily_return` 计算累计收益时，持有期间每天都参与。

```python
# 关键骨架
cross_up = (ma_s > ma_l) & (ma_s_prev <= ma_l_prev)
cross_dn = (ma_s < ma_l) & (ma_s_prev >= ma_l_prev)
sig = pd.Series(np.nan, index=df.index)
sig[cross_up] = 1
sig[cross_dn] = 0
sig = sig.ffill().fillna(0)  # 持仓维持 + 起始期空仓
```

### 4. 参数默认值

`short_window=7, long_window=14` —— 对 30 日 K 线足够触发 1-2 次交叉，可见效果；学员后续可以扫参。

## 不在范围

- 仓位金字塔加仓 / 减仓
- 止损止盈
- 多币种联动
```

```python
"""
双均线交叉策略。

短均线（默认 7 日）上穿长均线（默认 14 日）→ 信号 +1（做多）；
短均线下穿长均线 → 信号 0（空仓，不做空）；
其他时刻维持上一日信号。

实现按 lesson5/project/openspec/changes/add-dual-ma-strategy/{specs,design}.md 落地。
"""

from __future__ import annotations

import numpy as np
import pandas as pd


def dual_ma(
    df: pd.DataFrame,
    short_window: int = 7,
    long_window: int = 14,
) -> pd.Series:
    """双均线交叉信号。返回 Series，值 ∈ {0, +1}。

    防 lookahead：均线先 shift(1) 再比较，确保信号只基于昨日及以前。
    """
    if len(df) < long_window:
        # 数据不足以形成长均线，全程空仓
        return pd.Series(0, index=df.index)

    # shift(1) 后再 rolling，等价于"截至昨日"的均线
    ma_short = df["close"].shift(1).rolling(short_window).mean()
    ma_long = df["close"].shift(1).rolling(long_window).mean()

    ma_short_prev = ma_short.shift(1)
    ma_long_prev = ma_long.shift(1)

    cross_up = (ma_short > ma_long) & (ma_short_prev <= ma_long_prev)
    cross_dn = (ma_short < ma_long) & (ma_short_prev >= ma_long_prev)

    # 在交叉点写入信号；其他位置 NaN
    sig = pd.Series(np.nan, index=df.index)
    sig[cross_up] = 1.0
    sig[cross_dn] = 0.0
    # 前向填充 = 持仓维持；起始空仓
    sig = sig.ffill().fillna(0).astype(int)
    return sig
