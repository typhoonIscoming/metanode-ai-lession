- [ ] **Step 2: 写 test_backtest.py**

包含 3 个测试：

```python
"""backtest.run_backtest 的最小行为测试。

这一组测试是 L7 「验收」三节点中的第 2 节点——pytest——的真实样本。
重点是检查关键不变式：dual_ma 策略的信号必须经过 shift(1) 才进入回测，
确保信号日和成交日错开一天，绝对不能"今天的信号用今天收盘价成交"。
"""
import math
import pytest
from strategies import dual_ma
from backtest import run_backtest


def test_run_backtest_smoke():
    """冒烟测试：BTCUSDT limit=60 跑通，返回字典含 4 个关键字段。"""
    r = run_backtest(dual_ma, symbol="BTCUSDT", limit=60)
    assert isinstance(r, dict)
    for key in ("sharpe", "max_drawdown", "win_rate", "cumulative_return"):
        assert key in r, f"返回字典缺少 {key}"
        assert isinstance(r[key], float), f"{key} 应是 float，得到 {type(r[key])}"
        assert math.isfinite(r[key]), f"{key} 应是有限数，得到 {r[key]}"


def test_warmup_window_produces_zero_signal():
    """limit=30 时窗口不足 dual_ma 长均线 (默认 30)，应当全零退化为 buy_and_hold-like 结果。

    这是 dual_ma 的边界行为：长均线 = 30 时，前 29 天没有有效信号，
    第 30 天才出现第一个信号；又被 shift(1) 推到第 31 天——而 limit=30 一共就 30 行，
    所以没有任何持仓发生，4 个指标全 0。
    """
    r = run_backtest(dual_ma, symbol="BTCUSDT", limit=30)
    assert r["sharpe"] == pytest.approx(0.0, abs=1e-9)
    assert r["max_drawdown"] == pytest.approx(0.0, abs=1e-9)
    assert r["win_rate"] == pytest.approx(0.0, abs=1e-9)
    assert r["cumulative_return"] == pytest.approx(0.0, abs=1e-9)


def test_max_drawdown_non_positive():
    """max_drawdown 的语义是「曲线相对历史最高点回撤」，必然 ≤ 0。

    这条不变式如果不成立，说明回撤公式写反了——是 L7 演示「改坏→抓→修」
    的关键守门测试之一。
    """
    r = run_backtest(dual_ma, symbol="BTCUSDT", limit=60)
    assert r["max_drawdown"] <= 0.0, (
        f"max_drawdown 应 ≤ 0，得到 {r['max_drawdown']:.6f}——回撤公式可能写反"
    )
```

## Task 3: 写 `bin/verify.sh`

**Files:**

- [ ] **Step 1: 写 verify.sh**

```bash
#!/usr/bin/env bash
# lesson7/project/bin/verify.sh
# 三节点本地验收：ruff lint + pytest + Superpowers review skill
# 用法：bash bin/verify.sh
# 退出码：0 = 全绿，非 0 = 有任一节点失败

set -uo pipefail

# 切到 project 根（脚本所在目录的上一级）
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
cd "$SCRIPT_DIR/.."

# 颜色
GREEN='\033[0;32m'
RED='\033[0;31m'
YELLOW='\033[1;33m'
NC='\033[0m'

failed=0

echo -e "${YELLOW}[1/3] ruff check .${NC}"
if ruff check .; then
    echo -e "${GREEN}  ✓ ruff 通过${NC}"
else
    echo -e "${RED}  ✗ ruff 失败${NC}"
    failed=1
fi

echo -e "${YELLOW}[2/3] pytest tests/ -q${NC}"
if pytest tests/ -q; then
    echo -e "${GREEN}  ✓ pytest 通过${NC}"
else
    echo -e "${RED}  ✗ pytest 失败${NC}"
    failed=1
fi

echo -e "${YELLOW}[3/3] superpowers:requesting-code-review${NC}"
# 这一步只能在 Claude Code 会话内完成——脚本只打印提示，不真的调用。
# CI 里通过环境变量 CI=true 自动跳过整段，保留绿/红逻辑。
if [ "${CI:-false}" = "true" ]; then
    echo -e "${YELLOW}  - CI 环境，跳过 review skill（依赖 Claude Code）${NC}"
else
    echo -e "${YELLOW}  ⚠ 请在 Claude Code 里执行：${NC}"
    echo -e "${YELLOW}    /superpowers:requesting-code-review${NC}"
    echo -e "${YELLOW}    （让 review subagent 看本次 diff，本脚本无法替你跑）${NC}"
fi

echo
if [ "$failed" -eq 0 ]; then
    echo -e "${GREEN}=== 验收全绿 ===${NC}"
    exit 0
else
    echo -e "${RED}=== 验收红，请修复后重跑 ===${NC}"
    exit 1
fi
```
