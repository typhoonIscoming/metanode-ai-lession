# AI 驱动的软件开发提效实战课

> 面向研发人员的 10 节课实战训练——从基础工具到多 Agent 协作的完整链路。
>
> **前 7 课**是方法与工具课，配套讲义 + pptx + pdf + 演示 +（部分）讲稿 + 作业；**后 3 课**是综合项目实战，每节课直接是一个**可跑的真实工程仓库**（README + 完整源码），没有独立讲稿 / pptx / 单独作业——项目本身就是作业。

## 这门课讲什么

围绕 **Claude / Cursor / Codex / Copilot / MCP / Skill / OpenSpec / Harness / Superpowers / Agent Teams / Hermes Agent** 等 2026 年最具代表性的 AI 开发工具与方法，覆盖：

```
工具使用 → 进阶技巧 → 上下文接入 → 能力沉淀 → Spec 与规则约束 →
Harness 搭建 → Agent 工作流 → 综合项目实战 ×3
```

**前 7 课**讲方法与工具，**后 3 课**用三个真实黑客松级项目把所有能力串起来：

- L8 用 **Superpowers** 复刻 web3.career
- L9 用 **Claude Code Agent Teams** 做 Polymarket BTC 套利信号工具
- L10 用 **Hermes Agent** 做 Hyperliquid AI 策略驾驶舱

## 每课详细介绍

### [第 1 课：AI 开发提效全景与工具对比](./lesson1/)

**学完能做到**：把 Claude Code、Cursor、Codex、Copilot 放进一张"三种交互模式 × 谁适合谁"的地图；同一个 prompt 在 Claude Code 与 Cursor 里并排跑一遍 BTC K 线脚本，看清楚两者的结构、风格、交互轮次差异。

- 三种模式：聊天式 / IDE 内嵌 / 命令式 Agent
- 工具速览：Claude Code · Cursor · Codex · Copilot · 社区生态（Everything Claude Code · Superpowers）
- 20 条基础技巧（Cursor 10 + Claude Code 10）
- **demo**：[claude-demo](./lesson1/demo/claude-demo) vs [cursor-demo](./lesson1/demo/cursor-demo) —— 同一份 prompt 出来的两份 btc_kline.py，**故意不去重**，差异本身就是教学点

### [第 2 课：Claude Code × Cursor 高级技巧](./lesson2/)

**学完能做到**：让工具替你做更多事，而不是你不停指挥工具。

- Subagents 并行作业（隔离上下文跑探索 / 审阅 / 研究）
- Hooks 入门（SessionStart / UserPromptSubmit / PostToolUse）
- Cursor 进阶（Composer · Background Agents · .cursorrules）
- Plugins 生态（装 Everything Claude Code / Superpowers）

### [第 3 课：MCP 与外部能力接入](./lesson3/)

**学完能做到**：让 AI 看见你环境之外的东西。

- MCP 三类原语：Tools / Resources / Prompts
- 现场接 SQLite MCP，让 Claude 直接对 `prices.db` 写 SQL 查行情
- 权限与安全边界（read-only vs read-write）
- **project 快照**：[lesson3/project/](./lesson3/project)（btc_kline + prices.db + .mcp.json）

### [第 4 课：Skill 设计与能力沉淀](./lesson4/)

**学完能做到**：把高频任务沉淀成可复用的标准 Skill。

- Skill 与 Prompt / Rules / Subagent 的边界
- Skill 结构：触发条件 / 输入输出 / 执行步骤
- 现场设计并调用一个 **backtest skill**（输入策略函数 + 时间窗 → 夏普 / 回撤 / 胜率 / 累计收益 + PNG）
- **project 快照**：[lesson4/project/](./lesson4/project)（+ `.claude/skills/backtest/`）

### [第 5 课：规则体系与 Spec 驱动开发](./lesson5/)

**学完能做到**：从 vibe coding 升级到 spec-driven。

- 三层约束：rules · guidelines · spec 各自的作用与配合
- **OpenSpec 五段流程**：proposal → specs → design → tasks → implement
- 现场用 OpenSpec 完整跑一遍"双均线策略"feature
- **project 快照**：[lesson5/project/](./lesson5/project)（+ `openspec/` + `strategies/dual_ma.py` + `web/` 可视化 dashboard）

### [第 6 课：Harness 设计 — Superpowers 风格](./lesson6/)

**学完能做到**：让 AI 在长任务里跨会话续命。

- **Agent = Model + Harness** 公式（Martin Fowler / Anthropic / MongoDB 行业共识）
- 一个生活化类比：harness 就像工地的施工日志本
- Superpowers 14 个 skill 速览（writing-plans / executing-plans / subagent-driven-development 等）
- 真实演示：在 6 个 scenarios 上跑 dual_ma 策略 → /clear → 新会话续上 → 聚合 report
- **project 快照**：[lesson6/project/](./lesson6/project)（+ `plans/` + `reports/`）

### [第 7 课：Agent 工作流 — Agent Teams + Hermes](./lesson7/)

**学完能做到**：让多个 AI 同时干活、互相讨论、自己分配工作。

- **Claude Code Agent Teams（内嵌型）**：lead + teammates + shared task list + mailbox，teammates 之间能直接发消息
- **Hermes Agent（独立型，Nous Research MIT 155k stars）**：持久记忆 + 8 种入口（CLI / Telegram / Discord / Slack / WhatsApp / Signal / Email / Home Assistant）+ 模型无关
- 选型 & 组合：何时用哪个、二者通过 MCP 协议如何叠加
- **两个真实项目快照**：
  - [claude-agent-teams-project/](./lesson7/claude-agent-teams-project) —— Next.js + FastAPI 项目（讲师用 Agent Teams 跑出来的）
  - [hermes-project/](./lesson7/hermes-project) —— Binance Token Heatmap（讲师用 Hermes 跑出来的）

### [第 8 课：项目实战一 — 用 Superpowers 复刻 web3.career](./lesson8/)

**学完能做到**：用 Superpowers 全流程跑通一个完整产品——从 PRD 到可跑 demo。

- **49 个 commit、3 个版本迭代** 的全程 vibe-coding 记录
- 技术栈：NestJS + Prisma + Next.js + 3D 沉浸感动效
- 工作流：调研 → PRD ([PRD.md](./lesson8/PRD.md) · [backend-PRD.md](./lesson8/backend-PRD.md) · [frontend-PRD.md](./lesson8/frontend-PRD.md)) → 用 Superpowers writing-plans 拆 plan → 分块执行
- Superpowers 完整 plan 历史：[docs/superpowers/plans/](./lesson8/docs/superpowers/plans)

### [第 9 课：项目实战二 — Polymarket BTC 套利信号工具](./lesson9/)

**学完能做到**：用 Claude Code Agent Team 协同推进一个真实金融数据产品。

- **0 到 1 vibe-coded**——用 lead + 多 teammates 拆角色并行干
- 技术栈：FastAPI + alembic + Next.js + shadcn UI + 飞书卡片推送
- 完整工程化：discovery / scheduler / 多 LLM provider (gpt-5.5) / Docker Compose / smoke tests
- 设计文档：[backend-PRD](./lesson9/backend-PRD.md) · [frontend-PRD](./lesson9/frontend-PRD.md) · [QA checklist](./lesson9/docs/qa-checklist.md)

### [第 10 课：项目实战三 — AI Strategy Cockpit（Hyperliquid）](./lesson10/)

**学完能做到**：用 Hermes Agent 长跑 + 跨平台 + 模型无关的能力服务一个量化项目。

- 黑客松级 demo：输入交易目标 → AI 解释市场 + 选策略 + 调参 → 离线回测 → 一屏驾驶舱
- 技术栈：Next.js 15 + AIHUBMIX 聚合层（一个 key 调多家 LLM）
- 3 策略 × 3 风险偏好 = 9 种组合
- 数据：[Hyperliquid 历史 K 线 CSV](./lesson10/data)
- **完整 PRD**：[docs/ai-strategy-cockpit-prd.md](./lesson10/docs/ai-strategy-cockpit-prd.md)（1000+ 行）

## 怎么用这个仓库

### 学员视角

```bash
git clone <repo-url>
cd ai_lesson
# 跟课进度，挑一节进去
cd lesson6
cat README.md           # 学员讲义——step-by-step 可跟着做
```
