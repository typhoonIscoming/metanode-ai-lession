# Polymarket 调研说明

> **声明**：本文仅作科普与信息整理，不构成投资建议、法律意见或开户指引。预测市场涉及资金与合规风险，参与前请阅读官方规则并自行判断。

## 一句话它是什么？

**Polymarket（波利市场）** 是一个**预测市场（Prediction Market）**平台：人们针对「未来某件事会不会发生」进行买卖，**成交价被理解成市场对该事件发生的概率估计**。官方定位为全球规模最大的预测市场之一，并提供面向开发者的 API 与 SDK（见 [Polymarket 开发者文档](https://docs.polymarket.com/)）。

美国用户需注意：主站产品与文档体系另有 **Polymarket US** 分支说明，见 [US Docs](https://docs.polymarket.us/)。本文以国际站公开文档为主。

## 五个核心概念

### 1. 价格和概率是一回事（近似）

- 某一结果（例如「会发生 YES」）的份额价格通常在 **0.00～1.00 美元（USDC 计价思路）**之间。
- **0.30 的价格常被理解为「市场认为约 30% 会发生」**；这不是官方担保的「真实概率」，而是**当下买卖双方博弈出来的价格**。

### 2. 你不是在和「庄家」对赌，而是和用户交易

- 平台采用**订单簿（CLOB）**：你买入或卖出的对手方通常是**其他参与者**。
- 结果未定前，一般可以**卖出持仓**（流动性取决于市场），用来止盈或止损。

### 3. 抵押物与胜负结算（简化版）

官方「101」文档的直观模型（通俗理解）：

- 用抵押物（文档中介绍为 **pUSD / Polymarket USD**，与链上 USDC 一类稳定价值载体相关）支撑 YES/NO 这类**成对结果份额**；
- **猜对的一边**在清算后对应份额可赎回为 **1 美元/份**（量级概念），**猜错的一边归零**。

具体机制涉及智能合约与 **Conditional Token Framework（ERC1155）**，详见官方 [Polymarket 101](https://docs.polymarket.com/polymarket-101) 与 [Resolution（结算）](https://docs.polymarket.com/concepts/resolution)。

### 4. 结果怎么定？

文档说明会使用 **UMA Optimistic Oracle** 一类的**链上预言机/争议与投票机制**来推进结算；存在**提议 → 挑战期 → 争议处理**等流程。  
这意味着：**最终判定规则以平台/合约与预言机流程为准**，不是「你觉得新闻已经定了就一定立刻按你想的结算」。

### 5. 链与自托管（non-custodial）

官方强调 **非托管**：资产与头寸通过**钱包与智能合约**完成；你需要**保管好私钥/账户恢复方式**（文档提到 Magic Link、代理钱包等场景的恢复入口示例）。

## 你可能赚或亏的方式（极简例子）

假设某个「YES 会发生」的份额价格是 **0.18**（市场隐含约 18%）：

- 你若买入 YES，后来事件**真的发生**，粗略理解是 YES 份额走向兑付价值 **1.00** 的方向（未计费用与滑点等）；
- 若事件**未发生**，YES 份额可走**接近 0** 的方向；
- 事件未结束前，价格会随消息与订单流波动，你可能**提前卖出**锁定盈亏。

实际盈亏要加上：**手续费（若有）**、**买卖价差**、**流动性**、**结算规则**与**合规/地域限制**。

---

## 手续费（来自官方 Fees 文档的要点）

- **吃单（taker）**可能在部分品类市场产生手续费；**挂单（maker）**文档表述为不被收取 taker 费，且存在 **Maker Rebates（做市返佣）**计划，用于激励流动性。
- **地缘政治/世界事件类**市场在官方文档中写明为 **fee-free（免此类协议手续费）**。
- **Polymarket 自身**通常**不对 USDC 的存入/取出收取协议费用**，但**银行/卡商/跨链桥/第三方**可能另收费用。

费用按成交在**撮合时**计算，形式大致为（官方给出公式思路）：

`fee = C × feeRate × p × (1 - p)`

其中 `C` 为成交份额数量，`p` 为价格；**在 50% 附近费用最高、趋近 0 或 1 时费用更低**。不同品类 `feeRate` 不同，且可通过 API 查询某市场是否启用费用（文档提示查看 `feesEnabled` 等字段）。

权威细节以官方页面为准：[Fees](https://docs.polymarket.com/trading/fees)。

## 地域限制（非常重要）

在通过 API **下单**前，官方提供地理合规检查；部分国家/地区会被**完全限制**，或为 **仅平仓（close-only）**、或**仅前端限制**等。  
文档列出的限制**包含美国（US）在 Blocked** 类别；另有英国、法国、新加坡（close-only）、台湾（close-only）等条目。

**不要试图用「换 IP」等方式绕过合规**，这可能违反服务条款与当地法律。

- 检查接口（文档示例）：`GET https://polymarket.com/api/geoblock`
- 完整列表与说明：[Geographic Restrictions](https://docs.polymarket.com/api-reference/geoblock)

## 主要风险清单

| 类型 | 说明 |
|------|------|
| **本金风险** | 预测错误可能导致头寸价值归零或大幅亏损。 |
| **规则/结算风险** | 最终以预言机与市场规则为准，可能与公众舆论或媒体报道的时间点不一致。 |
| **流动性风险** | 可能难以及时按理想价格成交；点差大时成本更高。 |
| **费用与摩擦** | Taker 费（如适用）、桥与入金通道成本。 |
| **技术风险** | 私钥泄露、钓鱼、合约与集成风险等。 |
| **合规风险** | 你所在司法辖区的法律可能禁止或限制参与；务必以当地法规为准。 |
